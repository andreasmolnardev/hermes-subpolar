# Wave 0 Contracts

This directory is the normative contract packet for the new Subpolar runtime.
It describes one Bun/TypeScript product surface. It does not preserve or
re-document Python routes, Python configuration, legacy sessions, or legacy
compatibility behavior.

## Status And Authority

These documents are the approved Wave 0 source of truth. Implementations must
reject inputs that are not described here before a provider request, tool
execution, or durable write. The existing root `openapi.json` is not
authoritative: it still contains legacy `/api` and unversioned routes and is
not edited by this packet. It must be regenerated or replaced only when it
matches this packet exactly.

The words **MUST**, **MUST NOT**, **SHOULD**, and **MAY** are normative.

## Shared Types

Unless a document says otherwise, JSON values use this closed algebra:

```text
JsonNull    = null
JsonBoolean = true | false
JsonNumber  = finite JSON number
JsonString  = UTF-8 string
JsonArray   = JsonValue[]
JsonObject  = object with string keys and JsonValue values
JsonValue   = JsonNull | JsonBoolean | JsonNumber | JsonString | JsonArray | JsonObject
```

Contract objects are closed by default. An object only permits additional keys
when the contract explicitly declares a string-keyed map. Executable paths
MUST use named unions, records, or the JSON algebra above; they MUST NOT use
`unknown`, `any`, unvalidated casts, or executable open-ended values.

- **ID:** lowercase canonical UUIDv4, generated by the server unless stated otherwise.
- **Timestamp:** RFC 3339 UTC with `Z`, including milliseconds, for example `2026-08-07T12:34:56.789Z`.
- **Cursor:** opaque base64url string generated by the server; clients MUST NOT parse it.
- **Request ID:** UUIDv4 identifying one logical request. It is safe to echo to the caller.
- **Resource ownership:** every project, agent, session, message, tool approval, and persisted provider reference is scoped to the authenticated principal.
- **Limits:** byte and item limits are enforced before parsing or side effects. A limit is part of the contract even when its configured value differs by deployment.

The reusable wire records are also closed:

```text
User = { id: UUID, username: string }
RequestMessage = { role: system | user | assistant, content: string }
Usage = {
  inputTokens: non-negative integer,
  outputTokens: non-negative integer,
  totalTokens?: non-negative integer,
  cachedInputTokens?: non-negative integer,
  reasoningTokens?: non-negative integer,
  cacheCreationInputTokens?: non-negative integer,
  cacheReadInputTokens?: non-negative integer
}
```

## Documents

- [Errors and redaction](errors.md) defines the typed error envelope and public/private data boundary.
- [HTTP REST](http.md) defines the `/v1` resources, headers, JSON bodies, pagination, and SSE projection.
- [WebSocket events](websocket.md) defines `/v1/ws` commands, event envelopes, and ordering.
- [Authentication](authentication.md) defines bootstrap, password sessions, cookies, CSRF, and origin checks.
- [Configuration](configuration.md) defines the single behavioral configuration source and secret boundary.
- [Providers](providers.md) defines the initial OpenAI-compatible-only provider contract.
- [Tools](tools.md) defines shell, fixed-origin OpenAPI, MCP, approval, and execution policies.
- [Persistence](persistence.md) defines SQLite ownership, atomicity, recovery, idempotency, and retention.

## Explicit Non-Scope

- Only an OpenAI-compatible adapter is supported until separate native adapters are implemented and approved.
- Python execution, Python configuration parsing, Python provider codecs, Python extension loading, and legacy route/session compatibility are not fallbacks.
- A capability not represented by these typed contracts is rejected as unsupported; it is not dynamically interpreted.
