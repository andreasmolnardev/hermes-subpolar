# Platform Support

Subpolar supports one production deployment method: Docker Compose.

---

## Supported

| Deployment | Method | Notes |
| --- | --- | --- |
| Docker | [`docker compose up`](./installation.md#quick-start) | Supported for local, homelab, VPS, and remote browser access. |

Native desktop installers, Nix packages, bare-host production installs, and
separate cloud deployment modes are not supported.
